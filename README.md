# Mandal

A responsive grocery e-commerce website in a single self-contained `index.html` (no dependencies).

- Branded hero section, 8 shop-by-category tiles
- Live product search, category filtering, All / New in / Popular tabs, 5 sort orders, wishlist-only view
- Product cards with INR prices, discount badges, ratings, wishlist hearts, add-to-cart
- Cart drawer: quantity steppers, item removal, free-delivery progress bar (free over ₹499), subtotal / savings / total
- Checkout form with validation ending in an order confirmation with order ID (demo mode — no real payments)
- Weekend Bazaar deals band with live countdown, benefits strip, validated newsletter signup
- Full footer (shop / help / social), light + dark themes, responsive mobile layout

To add products, edit the `PRODUCTS` array in `index.html` (near `var PRODUCTS = [`).

Live: https://amleshwar19.github.io/mandal/
